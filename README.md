# CampusConnect

CampusConnect is a campus life application designed for Belmont Abbey College students. It provides helpful information and resources in one convenient location.

# Features

- Student Life: Explore campus activities, clubs, athletics, and student community information.
- Campus Resources: Find information about academic support, dining, library services, and student resources.
- Weather: View current weather conditions for Belmont, North Carolina, using live weather data.

# Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript
- Open-Meteo Weather API

# Purpose

The goal of CampusConnect is to make campus information more accessible and help students stay connected with campus life.
